# User Guide — Sharp Edge Barbershop

## Screenshots
Screenshots can be captured from the running application at `http://127.0.0.1:8000`. Key screens:

1. Home page — hero with shop background, gallery, services, barbers, address.
2. Book a visit — service, barber, date selection and time slots.
3. My bookings — reference numbers, status badges, cancel button for Pending bookings.
4. Track a booking — enter reference number to view details/status.
5. Admin — dashboard stats, filters, status update buttons.

## Customer steps
1. Click **Register** or **Log in**.
2. Click **Book**.
3. Choose a service, barber, and date. Free slots appear.
4. Pick a time, confirm mobile number, optionally add notes, then **Confirm booking**.
5. Copy the reference number shown in the success message.
6. Use **Track** and enter the reference number to see the status.
7. In **My bookings**, cancel a Pending booking if needed.

## Admin steps
1. Log in with admin credentials.
2. The **Admin** page opens automatically.
3. Use search/filter to find a booking.
4. Click a status button (Approve, Reject, Complete, Cancel) as allowed.
